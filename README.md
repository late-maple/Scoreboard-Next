[![workflow](https://github.com/late-maple/Scoreboard-Next/actions/workflows/gradle.yml/badge.svg)](https://github.com/late-maple/Scoreboard-Next/actions/workflows/gradle.yml)

A next-generation scoreboard mod for Minecraft, built on Fabric.

## Development

- Target: Minecraft **26.2** with Fabric loader, Java 25
- Build all: `./gradlew buildAndGather` (jars are collected into `build/libs`)
- Build the mod: `./gradlew :26.2:build`
- Run the game: `./gradlew :26.2:runClient`
